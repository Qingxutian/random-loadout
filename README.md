# 三角洲行动 · 随机配装网站

一个纯前端、无需后端的随机配装小工具，支持：

- 单人 / 双人 / 三人队伍
- 装备「全员相同 / 各自不同」
- 干员「全员相同 / 各自不同」（不同时保证不重复）
- 主武器 + 3 个配件、防具、头盔、背包、胸挂（无副武器槽位）
- 60+ 枪械全类别可选：突击步枪 / 战斗步枪 / 精确射手步枪 / 栓动狙击 / 轻机枪 / 冲锋枪 / 霰弹枪 / 手枪
- 可一键排除霰弹枪、栓狙、手枪
- 地图与难度选择，按对应战备门槛生成装备并显示达标状态
- 显示每人战备值和队伍战备总值
- 一键复制清单，发到群里方便队友照着配

## 怎么用

直接用浏览器打开 `index.html` 即可（双击即可），无需安装任何东西。

也可以在本地起一个静态服务器：

```powershell
cd random-loadout
python -m http.server 8080
```

然后访问 http://localhost:8080 。

## 怎么改数据

所有装备、干员、地图、难度都在 `data.js` 里，按同样格式增删即可。
价格单位为哈夫币，仅为娱乐参考，不代表游戏内实时行情。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 样式
- `data.js` — 全部数据（干员 / 武器 / 配件 / 防具 / 地图等）
- `core.js` — 随机逻辑（浏览器和 Node 通用）
- `app.js` — 界面交互
- `selftest.mjs` — 随机逻辑自测（命令行）
- `dom-smoke.mjs` — DOM 冒烟测试，验证页面脚本能正常渲染
- `browser-scope-test.mjs` — 模拟浏览器共享全局作用域，检查脚本之间没有命名冲突

## 测试随机逻辑

```powershell
node selftest.mjs
node dom-smoke.mjs
node browser-scope-test.mjs
```
