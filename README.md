# 三角洲行动 · 随机配装网站

一个纯前端、无需后端的随机配装小工具，支持：

- 单人 / 双人 / 三人队伍
- 装备「全员相同 / 各自不同」
- 干员「全员相同 / 各自随机」（各自随机时允许重复干员）
- 干员随机总开关：开启随机 / 固定干员（固定时干员不参与重随机）
- 单项锁定：每名队员的干员、主武器、配件、防具、头盔、背包、胸挂都可单独锁定，重随机时保持不变
- 配件同槽位互斥：瞄具 / 枪口 / 下挂 / 弹匣 / 枪管 / 枪托 / 护木 / 特殊，每槽最多一个，不会出现双瞄具、双枪口等冲突
- 弹药随机：1~5 级弹药，口径始终匹配主武器（可单独锁定，不计入战备值）
- 装备价值锁：可选设置每人装备价值上限，按战备值（武器+护甲+头盔+背包+弹挂）判定
- 顶部模式切换导航：单人模式 / 创建房间 / 加入房间
- 联机房间（GoEasy WebSocket 实时同步）：创建房间（生成 6 位房间号）、加入房间（输入房间号）、房间状态栏（房间号 / 在线人数 / 身份 / 连接状态），队员只读
- 联机权限：房主用 CommonKey 连接（可发布），队员仅用 SubscribeKey 连接（只订阅）；房主任何操作实时广播全量状态，队员收到后直接同步展示，不本地重随机
- 断线处理：GoEasy 自动重连，房间状态栏实时显示「连接中 / 已连接 / 重连中 / 连接失败」，退出房间自动退订并断开
- 地图-行动模式联动：难度下拉只展示当前地图真实存在的模式（如巴克什、航天基地仅机密/绝密），不再出现灰色错误选项
- 主武器 + 3 个配件、弹药、防具、头盔、背包、胸挂（无副武器槽位）
- 60+ 枪械全类别可选：突击步枪 / 战斗步枪 / 精确射手步枪 / 栓动狙击 / 轻机枪 / 冲锋枪 / 霰弹枪 / 手枪（含口径数据）
- 可一键排除霰弹枪、栓狙、手枪
- 地图与难度选择，按对应战备门槛生成装备并显示达标状态
- 显示每人战备值和队伍战备总值
- 一键复制清单，发到群里方便队友照着配

## 怎么用

直接用浏览器打开 `index.html` 即可（双击即可），无需安装任何东西。

也可以在本地起一个静态服务器：

```powershell
cd random-loadout
python -m http.server 8080
```

然后访问 http://localhost:8080 。

## 怎么改数据

所有装备、干员、地图、难度都在 `data.js` 里，按同样格式增删即可。
价格单位为哈夫币，仅为娱乐参考，不代表游戏内实时行情。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 样式
- `data.js` — 全部数据（干员 / 武器 / 配件 / 防具 / 地图等）
- `core.js` — 随机逻辑（浏览器和 Node 通用）
- `state.js` — 统一状态管理：所有配置 + 随机结果收敛为纯 JSON state 对象，可序列化，为联机同步做准备
- `goeasy.js` — GoEasy 通讯封装（插拔式）：连接 / 订阅 / 广播 / 在线人数 / 断线状态，不依赖具体页面逻辑
- `vendor/goeasy-2.13.24.min.js` — GoEasy SDK 本地化文件（npm goeasy@2.13.24 提取，离线可用）
- `app.js` — 界面交互
- `selftest.mjs` — 随机逻辑自测（命令行）
- `dom-smoke.mjs` — DOM 冒烟测试，验证页面脚本能正常渲染
- `browser-scope-test.mjs` — 模拟浏览器共享全局作用域，检查脚本之间没有命名冲突

## 测试随机逻辑

```powershell
node selftest.mjs
node dom-smoke.mjs
node browser-scope-test.mjs
```

## 联机说明

- 部署到 GitHub Pages 等任意静态托管即可，无需自己的服务器。
- 频道按房间号隔离：`rl_<房间号>`，每个房间互不干扰。
- 纯前端方案下，房主的 CommonKey 会随页面源码暴露（这是静态站点的固有限制）；
  队员侧只使用 SubscribeKey，没有发布权限。若后续需要更严格的安全控制，
  可在自己的服务器上用 ClientKey + SecretKey 生成 OTP 后再接入。
- SDK 已本地化到 `vendor/`，离线也能打开页面；联机时需要能访问 GoEasy 的 WebSocket 服务。
